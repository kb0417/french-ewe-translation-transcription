# Résultats expérimentaux

Ce dossier contient les fichiers de résultats générés pendant les expérimentations.

## Fichiers principaux

- `comparison_lstm_nllb.csv`  
  Tableau comparatif entre les modèles LSTM et NLLB pré-entraîné.

- `nllb_finetuning_fr_to_ewe_results.csv`  
  Résultats du fine-tuning NLLB avec LoRA pour la traduction français → éwé.

- `nllb_finetuning_ewe_to_fr_results.csv`  
  Résultats du fine-tuning NLLB avec LoRA pour la traduction éwé → français.

Ces résultats sont utilisés pour comparer les différentes approches testées dans le projet.
