# Résultats expérimentaux

Ce dossier contient les fichiers CSV résumant les résultats expérimentaux.

Fichiers principaux :

- `comparison_lstm_nllb.csv` : comparaison entre les modèles LSTM et NLLB pré-entraîné.
- `nllb_finetuning_fr_to_ewe_results.csv` : résultats du fine-tuning NLLB français → éwé.
- `nllb_finetuning_ewe_to_fr_results.csv` : résultats du fine-tuning NLLB éwé → français.
